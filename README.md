# Прошивка контроллера: Управление реле и светодиодом с таймером автоотключения

Небольшой проект на C++ (Arduino-style) для управления силовым реле и светодиодным индикатором с помощью одной физической кнопки. Поддерживает два режима работы в зависимости от длительности нажатия на кнопку.

## Как это работает (Логика прошивки)

Управление завязано на события от кнопки через объект `Button` и обратные вызовы (callbacks):

1.  **Короткий клик (`click`):**
    *   Переключает состояние реле (`rel->toggle()`).
    *   Если реле включилось, запускается таймер автоотключения на **250 циклов**.
    *   Светодиод начинает мигать с высокой частотой (интервал 2000).

2.  **Длинное нажатие (`press`):**
    *   Также переключает состояние реле.
    *   Если реле включилось, запускается увеличенный таймер на **500 циклов**.
    *   Светодиод мигает медленнее (интервал 20000), сигнализируя о долгом режиме.

3.  **Автоотключение:**
    *   Пока реле активно, объект `LedControl` в своем рабочем цикле инкрементирует счетчик времени через лямбда-функцию `timer`.
    *   Как только лимит (250 или 500) превышен, реле автоматически выключается, а светодиод гаснет.

4.  **Ручное выключение:**
    *   Если реле уже работает и пользователь снова нажимает на кнопку, реле выключается, а глобальный таймер сбрасывается в `0` в основном цикле `loop()`.

## Структура проекта

Проект разбит на логические модули (классы) для изоляции работы с железом:
*   `Button.h` — опрос пинов, защита от дребезга контактов и определение типов нажатий (`click`/`press`).
*   `Relay.h` — низкоуровневое управление пином реле (включение, выключение, проверка статуса).
*   `LedControl.h` — управление светодиодом (мигание, выключение) и интеграция с системным таймером.
*   `main.ino` (текущий файл) — инициализация периферии в `setup()` и диспетчеризация событий в `loop()`.

## Железо
Код написан аппаратно-независимым (через абстракции классов), поэтому легко переносится на любую Arduino-совместимую плату (UNO, Nano, ESP8266/ESP32). Номера пинов настраиваются внутри соответствующих классов.
